# DevPath Frontend

This is the initial React + TypeScript + Vite scaffold for DevPath.

## Scope

Implemented:

- Minimal application shell.
- Root and not-found routes.
- React Query provider.
- Basic error boundary.
- Smoke tests for routing and provider setup.

Not implemented:

- Dashboard, authentication, GitHub/Notion integration, score display, AI calls, or product data.

## Commands

```text
npm ci
npm run dev
npm run test
npm run build
```

Copy `.env.example` only for local environment setup. Do not commit real `.env` files.
